Que 5 →
● Clone https://github.com/zembutsu/docker-sample-nginx.git on your local system.
● Initialize one repo on your local system named Cloudethix-nginix-yourname and then
copy all the content from cloned repo to your local repo.
● Update the index.html and add the name CloudEthiX along with Hostname. Commit the
change to your local repository. Then create and push the code from the local repository
to your remote repository named Cloudethix-nginix-yourname under master branch.
● Once code is pushed, create a Docker hub public repository named
Cloudethix-nginix-yourname.
● Then build the docker image out of the dockerfile. Once an image is built, tag the image
and push that image to the docker hub repo you created.
● Create a deployment.yaml file with 2 replications in cloudethix_yourname Namespace
and use the container image that you have pushed to your docker hub repo. Once a file
is created, run the deployment in k8s cluster.
● Please prepare a document along with the snap and share it across

apiVersion: apps/v1
kind: Deployment
metadata:
  name: cloudethix-nginx
  namespace: cloudethix-achal

spec:
  replicas: 2

  selector:
    matchLabels:
      app: cloudethix-nginx

  template:
    metadata:
      labels:
        app: cloudethix-nginx

    spec:
      containers:
        - name: nginx
          image: docker.io/achalpadol/cloudethix-nginix-achal:v1
          ports:
            - containerPort: 80
